MTPDK NOTE MAP FIX - 2026-09-18

ROOT CAUSE
MTPDK's Map parameters reserve zero as "off". A nonzero stored mapping value N encodes MIDI note N-1.
The previous map generator used N directly, placing every articulation one semitone too high.
Examples from the plugin parameter dump:
- Kick Map1_1 = 37/128 -> MIDI note 36 (Kick), not 37.
- SideStick Map1_3 = 38/128 -> MIDI note 37 (SideStick), not 38.
- Snare Map1_2 = 39/128 -> MIDI note 38 (Snare), not 39.

CORRECTION
- Shifted every channel-1 drum note in the 128-bar performance down exactly one semitone.
- Notes changed: 1900 / 1900.
- MIDI CC events changed: 0 / 19. All 19 CC events retained their timing and values.
- Existing 128 CC-to-parameter links were left unchanged. Current project readback contains 128 MIDIPLINK entries spanning CC 0 through CC 127 on MIDI channel 16.
- Humanized timing and velocity values were left unchanged.
